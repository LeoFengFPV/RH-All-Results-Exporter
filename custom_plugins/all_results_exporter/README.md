# All Results Exporter 1.1.1

从 RotorHazard 已保存的场次读取飞手场次与逐圈记录，一键汇总成**单工作表 XLSX**，
用于整场赛事结束后的成绩复核。飞手数据按"场次 ID / 飞手场次 ID / 飞手 ID"关联，
不依赖呼号，可正确处理同场重名；频点取比赛当时保存的实际值。

## 导出内容

- 汇总整场赛事全部"已保存比赛"到一个工作表，每场每位参赛飞手一行。
- 圈号：Hole Shot / Staggered Start 从"第0圈"起算（第0圈为起跑圈）；First Lap 从"第1圈"起算。
- 总时间固定在最后一列；Staggered Start 的总时间取不含起跑圈的 `total_time_laps`。
- 全空的列不导出（如类别长期为空则自动不出现）；类别 / 分组 / 轮次仅在同一场次边界内合并单元格。
- 未分配飞手的空赛道位（有模块频点但无飞手、无圈速）不产生成绩行；整场无任何记录的场次保留一行占位以便核对。
- 以 `=` 开头的飞手名或文本按文本保存，不会被 Excel 当作公式。

## 安装

通过 RotorHazard "插件 → 上传" 上传整个 zip；或将 zip 中的
`all_results_exporter` 文件夹放入 `~/rh-data/plugins/` 后重启。
依赖 openpyxl。安装后在 "数据管理 → 导出器" 选择
`Export All Results (XLSX)`。

## 核对建议

- 在实机上核对当前 RotorHazard / RHAPI 版本、下载文件可被 Excel / WPS 正常打开。
- 分别核对 Hole Shot、First Lap、Staggered Start 的起始圈号及总时间字段。
- 把已保存比赛数、每场参赛飞手数与表格行数一 一对照；零圈、未排名场次保留，空赛道位不出现。
- 核对被裁判删除或补录的圈次，并确认"频点"与比赛时保存值一致。
- 大型赛事请在非计时阶段导出，记录实际耗时、内存与页面响应。

数据来源为已保存赛事；未保存或被丢弃的现场圈记录不属于导出范围。
